# Better UI

Better UI is a mod that improves Geometry Dash's UI! Here's what it changes:

* Completely overhauls the icon kit by adding a dropdown to choose which icon to customize;
* Makes the stats menu clearer and more organized;
* Adds a new tab in the creator menu called **"SPECIAL LEVELS"** that includes daily, weekly, and event levels;
* Moves Map Packs to the search menu;
* Replaces the normal Demon filter window with a quick dropdown of all Demon difficulties.
